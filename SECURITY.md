# Security Policy

## Reporting a vulnerability

Do not open a public issue for an unresolved security vulnerability.

Please report suspected vulnerabilities privately by emailing the repository maintainers at the security contact listed in the GitHub repository profile or security advisory interface. Include:

- A description of the issue and affected versions
- Reproduction steps or a minimal proof of concept
- The expected and observed behavior
- Any relevant logs or environment details

Maintainers will acknowledge the report, assess impact, coordinate a fix, and publish an advisory when appropriate.
